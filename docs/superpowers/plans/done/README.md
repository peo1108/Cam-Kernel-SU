# Plan đã xong

Mọi plan ở đây đã làm xong và có trong bản phát hành. Các ô `- [ ]` là danh sách bước lúc lập plan, không được tick trong lúc làm: đừng đọc là việc còn dở. Hiện trạng thật của từng tính năng nằm trong `docs/CAM_CHANGES.md` (mỗi file có dòng "Trạng thái" chỉ chỗ).

Plan mới đặt ở `docs/superpowers/plans/`; làm xong thì thêm dòng "Trạng thái" và chuyển vào đây.
